The Big Tuna - Guitar Tuner

The tuner doesn't react

Check that Big Tuna has microphone access: on iPhone, Settings → Big Tuna → Microphone; on Android, Settings → Apps → Big Tuna → Permissions → Microphone. Then pluck a single string firmly, close to the phone.

It shows the wrong string

Mute the other strings and let one ring. Or turn off Auto and tap the string you're tuning, so the tuner measures against that note only.

My band tunes to 432 Hz (or 442 Hz)

Settings → Calibration (A4) sets the reference pitch from 415 to 466 Hz.

I bought Big Tuna Pro but it's locked

Open the gear icon → Big Tuna Pro and tap Restore purchase. Make sure you're signed in to the same Apple ID or Google account you bought it with. Pro is a one-time purchase: there is no subscription to renew or cancel.

Something else? Send a message

It lands straight in my inbox. Tell me what happened and what phone you're on, and I'll reply by email.
